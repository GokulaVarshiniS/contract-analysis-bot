# Contract Risk Assessment System

## Description
This project analyzes legal contracts and predicts risk levels using NLP techniques.
It extracts clauses, scores risk, and generates a summary report.

## Tech Stack
- Python
- Streamlit
- NLP
- OpenAI API

## Project Structure
- app.py : Main Streamlit app
- src/ : Core logic files
- notepad_uploads/ : Sample contract files

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py
